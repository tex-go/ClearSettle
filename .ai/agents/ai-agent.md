# AI Agent

Role: Future intelligence layer for anomaly detection, classification and insights.

Responsibilities
- Run anomaly detection for settlements, classify seller behaviors, suggest root-cause candidates.
- Provide explainability metadata and confidence scores for predictions.

Data Requirements
- Needs normalized, auditable inputs with provenance and labeled historical anomalies for supervised models.

Collaboration
- Works with `reconciliation-agent` for feature signals and `documentation-agent` to publish model notes and drift reports.
