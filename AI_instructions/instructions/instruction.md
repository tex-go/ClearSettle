# ClearSettle AI Operating System

## Project

ClearSettle is an eCommerce reconciliation SaaS for Indian marketplace sellers.

## Stack
- React 18
- Vite
- FastAPI
- Docker
- Nginx
- Playwright
- Ollama
- Flowise

## Core Rules
- No Tailwind
- No external UI kits
- Docker compatible architecture only
- No nested template literals
- Use function declarations
- Validate imports before completion
- Never silently break APIs

## Git Rules
Pull → Build → Validate → Commit → Push

## Testing
- Frontend syntax checks
- Backend import validation
- Playwright smoke tests
- Docker boot validation

## Forbidden
- Random dependencies
- Architecture rewrites
- Massive unmaintainable files
- Silent API changes
